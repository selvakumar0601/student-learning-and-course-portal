
# Student Learning & Course Portal

A responsive web application that helps students explore courses, enroll in learning programs, and track lesson completion.

## Features

- Responsive design
- Course listing and course cards
- Search courses
- Category-based filtering
- Course details and lessons
- Course enrollment
- Lesson completion tracking
- Progress percentage calculation
- Student dashboard
- LocalStorage progress saving

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Google Fonts (Poppins)

## Color Theme

- Green: #16A34A
- Light Blue: #BAE6FD
- White: #FFFFFF

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select Open with Live Server.

## Modules

### Course Listing
Displays available courses with descriptions and enrollment options.

### Course Search
Search courses using their titles or descriptions.

### Course Enrollment
Allows students to enroll in available courses.

### Lesson Tracking
Students can mark lessons as completed and track progress.

### Dashboard
Displays enrolled courses and completion progress.

## Data Storage

The application uses browser LocalStorage to store course enrollment and lesson progress.

Note: Data is stored locally in the browser and is not synchronized across devices.
